🛠️ Development Setup Guide ​

Follow these steps to initialize the WealthFam ecosystem in your local development environment.

📋 Prerequisites ​

  • Python 3.10+
  • Node.js 18+
  • npm or yarn
  • Git

⚙️ Installation ​

  1. Clone the Repositories: We recommend using the Workspace Setup Script in the Infra repository to clone all necessary modules.

  2. Backend Setup:

    bash
    cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload

  3. Frontend Setup:

    bash
    cd frontend
npm install
npm run dev

  4. Parser Setup:

    bash
    cd Parser
pip install -r requirements.txt
python main.py

  5. Admin Stack Setup (Admin-Backend & Admin-Web):

    bash
    # Admin-Backend (Port 8002)
cd Admin-Backend
pip install -r requirements.txt
uvicorn app.main:app --port 8002 --reload

# Admin-Web (Port 5174)
cd Admin-Web
npm install
npm run dev

    Or launch the entire stack at once via ./wf.sh dev (or ./wf.sh dev --admin for Admin only).
