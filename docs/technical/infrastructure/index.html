🏗️ System Infrastructure ​

The WealthFam ecosystem is supported by a set of robust orchestration and repair utilities designed to maintain system health and automate complex management tasks.

🛠️ Management & Orchestration ​

⚙️ System Orchestration ​

Logic for managing the lifecycle of backend and parser services.

🧹 Database Maintenance ​

Automated vacuuming and indexing scripts for DuckDB optimization.

🩹 Recovery Tools ​

Utilities for patching and recovering schema state in the event of failure.

🗺️ Logical Layout ​

Infrastructure is decoupled from application logic to ensure that deployment environments can be swapped or hardened without affecting the core financial engine.

  • Environment Sync: Synchronized variable management across production/demo.
  • Microservice Decoupling: Standalone service containers.
  • Nginx Ingress: Centralized traffic management.
