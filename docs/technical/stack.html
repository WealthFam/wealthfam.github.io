🛠️ The WealthFam Tech Stack ​

WealthFam is built on a "Local-First, AI-Augmented" philosophy. Every technology in our stack is chosen for its performance, privacy characteristics, and developer experience.

🚀 Backend: FastAPI & Python 3.10+ ​

We chose FastAPI as the central orchestrator for its modern features:

  • High Performance: Built on Starlette and Pydantic, it is one of the fastest Python frameworks available.
  • Type Safety: Leveraging Python type hints for automatic validation and interactive API documentation (Swagger/OpenAPI).
  • Asynchronous Support: Perfect for handling multiple concurrent ingestion streams (SMS, Email, Web).

🗄️ Database Stack: PostgreSQL & DuckDB ​

WealthFam utilizes a dual-database approach designed for both transactional robustness and telemetry timeseries:

  • PostgreSQL (Core Backend DB): Used as the primary relational database. This provides robust multi-user transactional integrity, concurrency support, indexing, and standard schema migrations using Alembic (plus Document Vault metadata, cross-source deduplication indices, and brand_logos).
  • DuckDB (Admin Telemetry Timeseries & Control Plane): Embedded timeseries database managed by Admin-Backend (data/telemetry.duckdb) for anonymous API latency metrics, parser events, client crash events, scrubbed system logs, active 30s endpoint probes, and declarative parser templates.
  • Stateless Financial Parser: The Parser microservice is 100% stateless and code-driven. It performs zero disk writes, persists zero customer PII, and handles idempotency through an in-memory thread-safe 5-minute sliding LRU cache (RecentSubmissionCache).

🎨 Frontend: Vue 3 & Material 3 ​

Our web interface is designed for clarity and responsiveness:

  • Vue 3 (Composition API): Provides a clean, reactive architecture for complex financial dashboards.
  • Vite: The next-generation frontend tool that ensures near-instant development starts and builds.
  • Material Design 3 (M3): We strictly follow M3 principles to ensure the UI is accessible, beautiful, and feels native on every device.
  • Tailwind CSS: For high-fidelity, utility-first styling that doesn't bloat the bundle.

📱 Mobile: Flutter ​

The WealthFam Mobile app (Android) is built with Flutter:

  • Native Performance: Compiles to ARM machine code for smooth 60fps animations.
  • Native Integration: Essential for our background SMS listeners and device hashing capabilities.
  • Single Codebase: Allows us to maintain a consistent experience if we expand to iOS in the future.

⚡ Deterministic Engine: Native Python Parsers ​

Rather than relying on expensive, nondeterministic cloud LLMs that risk privacy exposure:

  • Deterministic Accuracy: 23+ Indian bank parser classes and 100+ compiled regexes provide >95% confidence on financial alerts.
  • Sub-Millisecond Speed: In-memory parsing finishes in < 0.5ms with zero network hops.
  • Complete Privacy: Customer transaction text never leaves the local environment.
