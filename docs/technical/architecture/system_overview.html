🏛️ System Architecture Deep Dive ​

WealthFam is engineered as a high-concurrency, modular microservice ecosystem. Each component is architecturally decoupled to ensure systematic resilience, Precision accuracy, and local-first data privacy.

🧩 Architectural Philosophy ​

  • Modular Microservices: Every core pillar (Backend, Frontend, Parser, Mobile) exists as an independent unit. This allows for categorical scaling and simplifies regression testing.
  • Sovereign Circle Model: Unlike traditional cloud-first apps, WealthFam creates a "Sovereign Circle" around your data. Your backend database (PostgreSQL) is isolated, and all parser/AI ingestion processing is kept local and distinct per tenant.
  • Precision Ledger Integrity: Every transaction ingested is subjected to deterministic hashing (MD5/SHA256). This ensures that no data point is duplicated across the SMS, Email, or Manual ingestion streams.
  • AI-Augmented Parsing: We utilize Google Gemini for unstructured data extraction, acting as a high-intelligence fallback when traditional regex patterns fail.

📡 Core Component Taxonomy ​

1. The Core Engine (Backend) ​

  • Framework: FastAPI (Asynchronous Python)
  • Persistence: PostgreSQL (Core relational ledger) and DuckDB (Enterprise Admin telemetry & logs)
  • Responsibility: Serving as the relational orchestrator, managing the lifecycle of financial entities, enforcing strict schema validation via Pydantic (strict=True), and ensuring absolute mathematical precision via a global Decimal standard.

2. The Precision Harvester (Parser) ​

  • Framework: Python Microservice (FastAPI)
  • Architecture: 100% Stateless & Code-Driven Engine (< 0.5ms extraction, in-memory 5-minute LRU duplicate submission guard, zero financial PII stored at rest)
  • Logic: Native compiled Python bank parsers and PDF statement extractors (HDFC, ICICI, SBI, Axis, Kotak, etc.) with asynchronous scrubbed telemetry shipping to Admin-Backend
  • Responsibility: Real-time deterministic normalization of raw SMS, Email, Bank Statement, and CAS payloads into the unified transactional schema.

3. The WealthHub (Web App) ​

  • Framework: Vue 3 + Vite
  • UI System: Material 3 / Triage Design Language
  • Responsibility: Advanced data visualization, Precision auditing of transactions, and comprehensive budget management.

4. Precision Pulse (Mobile App) ​

  • Framework: Flutter (Native Android)
  • Background Engine: Android Foreground Services
  • Responsibility: Non-intrusive SMS listening, real-time synchronization with the Sovereign Circle backend, and offline-cached anonymous client telemetry (app lifecycles, SMS listener heartbeats, batch sync timings, sanitized crash signatures).

5. Enterprise Admin & Telemetry Control Plane (Admin-Backend & Admin-Web) ​

  • Framework: FastAPI (:8002) + Vue 3 (:5174 dev / :8080 Docker)
  • Persistence: Embedded DuckDB Timeseries (data/telemetry.duckdb) & data/logos/ assets (Zero direct PostgreSQL connections)
  • Communication: Strictly proxies requests to Backend (:8000) and Parser (:8001) via REST APIs (httpx)
  • Responsibility: Unified zero-PII telemetry & sanitized log ingestion, 30s active endpoint SLA probing, code-first Parser Testing Studio & multi-source sandbox (SMS/Email text tester, scratchpad regex prototyping, and live PDF statement inspection via pdfplumber), consent-driven training inbox with format-preserving structural anonymization and deduplication counters, and Brand Logo/Regex management. Completely isolated from client financial data.

6. Anonymous Telemetry & Observability Pipeline ​

  • Philosophy: Mathematical zero-PII assurance. All routes are normalized to parameterized templates (/api/v1/finance/accounts/{id}), logs are scrubbed at the client/producer before leaving the process (stripping JWTs, emails, PANs, currencies, account numbers, and phone numbers).
  • Producers:
    • Backend: Non-blocking ASGI TelemetryMiddleware + AsyncHttpLogHandler with anti-recursion guards and background load-shedding queues flushing to Admin-Backend. Exposes POST /api/v1/telemetry/ingest proxying for mobile clients.
    • Parser: ASGI middleware, AsyncHttpLogHandler, and pipeline extraction metrics (record_parser_event).
    • Web-App: Client-side navigation latencies, API error rates, and unhandled Vue exceptions, with sendBeacon on page unload and transparent user onboarding/settings toggles.
    • Mobile-App: Offline-first SharedPreferences event queue (FIFO 100 max) surviving network outages, with decoupled target URL resolution (backendUrl proxy or dedicatedTelemetryUrl).

🔄 Data Lifecycle & Synchronization ​

🛡️ Security & Privacy: The Sovereign Circle ​

  1. Isolation: Your backend instance is locally managed. Your data is never pooled or used for training external models.
  2. Encryption: Communication between services is secured via TLS, and sensitivity labels are applied to all financial metadata.
  3. Auditability & Integrity: Every mutation in the database is anchored with a Precision audit trail. Our Soft-Delete Architecture (using is_deleted flags) ensures that historical financial mappings are never permanently lost, allowing for complete transaction reconstruction and point-in-time auditing.
  4. Absolute Precision: To prevent longitudinal wealth drift, all financial calculations are performed using the Decimal standard. This eliminates the accumulated rounding errors inherent in floating-point arithmetic.
  5. Identity Preservation: High-frequency recalculations (e.g., Mutual Fund average cost rebuilding) utilize surgical In-Place Updates. This preserves entity UUIDs across the entire lifecycle, ensuring that frontend caches, goals, and history links remain perfectly synchronized.
