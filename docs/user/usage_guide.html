📖 WealthFam — How To Use Guide ​

A comprehensive operating manual for both the Web Dashboard (VueJS) and the Mobile App (Flutter).

🚀 1. Getting Started ​

First-Time Registration (Web) ​

  1. Navigate to the WealthFam URL and click Register.
  2. Enter a Family Name (this creates your Tenant — the shared family workspace).
  3. Fill in your email, password, and profile details (full name, avatar emoji).
  4. You are now the OWNER of the tenant with full administrative rights.

Mobile App Setup ​

  1. Install the APK on your Android device.
  2. On first launch, go to Settings → Server Configuration and enter your backend URL.
  3. Login with the same credentials used on the web.
  4. The app will generate a unique Device ID. If required, the Tenant Admin must approve this device from Web → Settings → Devices before sync can begin.

Adding Family Members ​

  1. Go to Settings → Family on the web dashboard.
  2. Click Add Member and provide their email and assign a role:
    • Adult: Full financial access.
    • Child: Restricted to personal goals only.
    • Guest: Read-only.
  3. The new member can then register with that email and will automatically join your family tenant.

📱 2. SMS Transaction Sync (Mobile — Android) ​

Initial Permission Setup ​

  1. Open the mobile app. On first use, it will request SMS and Location permissions.
  2. SMS Permission: Required for reading bank transaction messages. Grant "Allow".
  3. Location Permission: Set to "Always Allow" for highest Precision precision. Without this, GPS coordinates will be missing or use last-known position.

How SMS Sync Works ​

  • Once permissions are granted, the app listens for incoming SMS in real-time, both in foreground and background.
  • Each SMS is locally hashed (SHA-256) to prevent duplicates, then sent to the backend with GPS coordinates.
  • The backend's AI parser extracts the transaction details (amount, date, merchant, account) and either auto-confirms or places it in the Triage Queue for review.

Enabling the Foreground Service (Recommended) ​

  1. Go to Mobile App → SMS Management → Toggle "Foreground Service".
  2. This keeps a persistent notification showing Today: ₹X • Month: ₹Y.
  3. Benefits: More reliable background operation, real-time spending awareness, and poll-based alert delivery when WebSocket is disconnected.

Manual Sync & Catch-Up ​

  • Tap "Sync Now" on the SMS Management screen to:
    1. Retry all queued offline messages.
    2. Scan the device inbox for the last 72 hours of unprocessed messages.
  • Use "Push All Unsynced" for a complete inbox scan (all time).

Checking Sync Status ​

  • The SMS Management screen shows:
    • Last Sync Time: When the last successful sync occurred.
    • Messages Synced Today: Counter resets daily.
    • Queue Count: Number of messages waiting for retry.
    • Debug Logs: Raw payloads sent to the backend (enable in settings).

🏦 3. Account Setup ​

Adding Accounts (Web) ​

  1. Go to Settings → Accounts and click Add Account.
  2. Choose the account type:
    • Bank: Savings/Checking (enter an account mask like XX1234 for SMS matching).
    • Credit Card: Enter credit limit, billing day, and due day for cycle intelligence.
    • Wallet: Digital wallets (Paytm, PhonePe, etc.).
    • Loan: Will prompt for loan details (see Loans section).
  3. The Account Mask is critical — it's the last 4+ digits of your account number that appears in bank SMS messages (e.g., *1234). This is how WealthFam knows which account an SMS transaction belongs to.

Credit Card Intelligence ​

Once you set the Billing Day and Due Day for a credit card, WealthFam performs Precision cycle analysis:

  • Statement Balance: Automatically calculated even if the bank doesn't report it (Current Balance - Unbilled Purchases - Payments Since Statement).
  • Unbilled Spend: Live tracking of new purchases in the current cycle that haven't shifted to a statement yet.
  • Utilization Tracking: Visual indicators and alerts for high debt-to-limit ratios.
  • Next Due Date: Real-time ticker showing days remaining until payment is required.
  • Credit Outlook: A dedicated dashboard panel for aggregated debt health across all cards.

📄 4. Bulk Statement Ingestion (Web) ​

For banks or cards not yet supported by real-time SMS sync, or to backfill historical data, use the Bulk Ingestion feature.

Uploading a Statement ​

  1. Navigate to Banking → Statements on the web dashboard.
  2. Click Upload Statement.
  3. Select your bank's PDF or CSV file.
  4. If the PDF is encrypted, the system will attempt to auto-unlock it using common patterns (e.g., PAN + DOB). If it fails, you will be prompted for a Manual Password.

Reconciliation & Rule Generation ​

  1. Once uploaded, the statement appears in the list. Click Reconcile.
  2. A bulk ingestion dialog will appear showing all extracted transactions.
  3. Smart Classification:
    • Transactions already matched by existing rules or AI will have a category pre-selected.
    • For new merchants, select a category from the tree-based dropdown.
  4. Automated Rule Creation:
    • Toggle "Save Rule" to automatically create a classification rule for that merchant.
    • The rule is generated based on the transaction's description, ensuring future statements are auto-categorized.
  5. Click Confirm Import to move all selected transactions into your ledger.

Managing Statements (Filter, Edit, Reprocess & Delete) ​

  • Filter & Search: Filter statements by status (All, Parsed, Pending, Failed), statement type, or search by filename. Toggle the Show Attended pill/chip (Show Attended ↔ Showing Attended) to flip between hiding attended statements (default) and showing all statements.
  • Edit Statement Metadata: Click Edit on a statement to update its display filename (automatically synced with its linked Document Vault entry), statement_type, or linked account (re-linking an account automatically triggers reprocess/reconciliation for FAILED statements). Extracted statement line items remain read-only for audit integrity.
  • Password Retry & Partial Unlock: On locked (PENDING) or failed statements, click Unlock / Reprocess to supply a manual password. If unlocking succeeds and saves the decrypted PDF into the Vault even when downstream parsing still needs attention, WealthFam keeps the unlocked PDF accessible in Vault alongside the diagnostic status.
  • Single & Bulk Delete: Delete an individual statement or select multiple rows for Bulk Delete, with options to remove linked unreferenced Vault PDFs and create a sender ignore rule in one step.

Statement Attendance & Review Lifecycle ​

  • Hidden by Default: To keep your working inbox focused strictly on actionable items, attended statements are hidden by default on both the Web App and Mobile App (is_attended=false).
  • Show Attended / Showing Attended Toggle:
    • Web App: Click the Show Attended button in the filter toolbar. When active, it displays Showing Attended with an emerald badge, showing both attended and unattended statements. Clicking it again hides attended statements.
    • Mobile App: Tap the Show Attended chip in the horizontal filter header. It updates dynamically to Showing Attended, toggling the view between unattended only and all statements.
  • Real-Time Auto-Advance: When you mark a statement as attended while showAttended is off, it is smoothly removed from your active list and the inspector automatically advances to select the next pending statement.
  • Mark Attended (✓ Attended): When you have completed reviewing a statement, click Mark Attended. This moves the statement into the attended archive, clears the attention queue, and protects the statement from accidental modification (disabling checkboxes, edit, and reprocess actions).
  • Import Status vs. Attended Status: Marking a statement as attended does not import un-imported transactions.
    • Transactions previously imported into your portfolio or matched to your bank ledger display ✓ Imported or ✓ Matched.
    • Transactions that were skipped display neutral Unimported (CAS) or Unmatched (Bank) indicators.
    • If you close a statement with un-imported transactions remaining, an amber banner highlights: Notice: Marked as Attended with N unreconciled transaction(s).
  • Reopening a Statement: If you need to import skipped transactions later, click Reopen. The statement immediately returns to review mode, unimported transactions switch back to Ready, and checkboxes re-enable.

Mutual Fund CAS Statement Ingestion & Portfolio Import ​

  • Automated Scheme & Folio Mapping: CAS PDFs (CAMS, KFintech, CDSL, NSDL) and AMC SOAs (Nippon India, Quant, Groww) are automatically parsed via casparser 1.x (pypdfium2 engine) and matched against the AMFI mutual fund catalogue.
  • Duplicate Detection: The system checks extracted transactions against your existing investment orders. Transactions already present in your portfolio are badged as Duplicate and automatically excluded from import selection.
  • Import to Portfolio: Click Import to Portfolio to ingest selected mutual fund transactions into your active portfolio holdings and orders. Holding balances and units recalculate automatically with zero manual entry.
  • Reprocessing Dynamic Sync: If duplicate status changes after updating other accounts or holdings, click the Reprocess / Re-evaluate action to re-verify the PDF against your latest live ledger.

Blocking Unwanted Statement Emails (Statement Ignore Rules) ​

  • Click the 🚫 Ignore action on any unwanted promotional, margin, or non-statement PDF attachment to block future emails matching the Sender, Email Subject, or Filename Keyword, and optionally remove existing matching PENDING/FAILED statements while keeping PARSED statement history untouched.
  • Click Ignored Rules in Banking → Statements (or manage rules under Settings → Ingestions) to view, add, or remove STATEMENT ignore rules at any time.

📧 5. Email Sync (CAMS & Bank Emails) ​

Setting Up Email Sync ​

  1. Go to Settings → Email Sync on the web dashboard.
  2. Click Add Email Configuration.
  3. Provide:
    • IMAP Server: imap.gmail.com for Gmail, imap-mail.outlook.com for Outlook.
    • Email: Your email address.
    • Password: For Gmail, use an App Password (not your regular password).
    • Folder: Usually INBOX.
  4. Enable Auto-Sync to let the system check for new emails every 3 hours automatically.

Manual Email Sync ​

  • On the Email Settings page, click Sync Now to trigger an immediate scan.
  • The sync will fetch unread (or all, depending on configuration) emails, filter out noise, and parse financial transactions.
  • Results appear in the Sync Logs section.

CAS Sync — CAMS / KFintech / CDSL / NSDL (Mutual Funds) ​

  1. Ensure you have an email configuration set up.
  2. Navigate to Mutual Funds → Settings (or the CAS Sync section).
  3. If your CAS PDFs are password-protected, enter the standard password (usually your PAN + DOB).
  4. Click Sync CAS — the system will:
    • Scan for emails from camsonline, eCAS@cdslstatement.com, cdslindia, KFintech/NSDL senders, or with subject "Consolidated Account Statement".
    • Download PDF attachments into the persistent Document Vault.
    • Automatically unlock, vault, and parse them.
    • Map extracted transactions to mutual fund schemes and update your holdings.

Automated Statement Fetching (Bank Statements) ​

Beyond Mutual Funds, WealthFam can automatically monitor your inbox for bank and credit card statements.

  1. When Auto-Sync is enabled, the system scans for emails containing "Statement" or "E-Statement" from supported financial institutions.
  2. Detected PDF attachments are automatically downloaded to the Vault.
  3. If the statement's bank is recognized (e.g., HDFC, Swiggy HDFC), the system pre-processes the statement and places it in Banking → Statements for final reconciliation.
  4. Zero-Touch Ingestion: This turns the monthly statement routine into a simple "Click to Reconcile" action without ever downloading files to your computer.

  2. The overview shows all holdings grouped by scheme with:

Fund Details & Transaction Management ​

Click any scheme to open the Deep-Dive Management Modal:

  • Consolidated History: View every historical BUY/SELL order with audited NAVs and unit counts.
  • Surgical Corrections: Edit or soft-delete individual transactions directly from the history grid to correct data entry errors.
  • Predictive 'What-If' Analysis: Before deleting a transaction or a folio, the system provides a live projected impact—showing exactly how your Profit/Loss, Invested Value, and XIRR will change.

Performance & Precision ​

  • Absolute Accuracy: All portfolio calculations (Average Price, P&L, Value) are performed using the Decimal precision standard, eliminating longitudinal rounding errors common in other apps.
  • XIRR Engine: Annualized returns are calculated based on your actual verified cash flows, including buy/sell timings and current market valuations.

🧠 Mutual Fund Intelligence Suite ​

Navigate to the Intelligence tab on Web or the Intelligence view on Mobile to access specialized analytical engines:

  1. Tax Optimization & Tax-Loss Harvesting:

    • ₹1.25L LTCG Exemption Headroom: Real-time gauge tracking utilized vs available annual long-term capital gains tax-free headroom under the Indian Finance Act 2024.
    • FIFO Lot Breakdown: Lot-by-lot decomposition of each fund purchase showing holding days, cost basis, unrealized gain, and tax categorization.
    • Near-LTCG Alerts: Identifies short-term lots approaching the 365-day threshold (315–365 days) to help prevent selling prematurely and incurring 20% STCG tax instead of 12.5% LTCG.
    • 1-Click Harvesting: Actionable suggestions to harvest tax losses or capture tax-free LTCG gains up to the remaining annual limit.

  2. Portfolio Overlap & Entity Concentration:

    • Pairwise Overlap Matrix: Visual heatmap quantifying common portfolio holdings across fund pairs $\sum \min(w_A, w_B)$.
    • Aggregate Stock Concentration: Identifies true aggregate exposure across all schemes (e.g. your total portfolio holding in HDFC Bank or Reliance across Large Cap, Flexi Cap, and Index funds).
    • Risk Guardrails: Generates warning alerts if any single corporate entity exceeds 10% or critical alerts if it exceeds 15% of your total equity portfolio.

  3. Sectoral Heatmap & Market Cap Exposure:

    • 12 Economic Sectors: Color-coded breakdown of economic sector allocations (Financials, Technology, Healthcare, Auto, Energy, etc.).
    • Market Cap Distribution: Segmented breakdown across Large Cap, Mid Cap, Small Cap, and Cash/Debt.
    • Pareto Concentration Drilldown: Displays key constituent companies contributing to each sector along with fund-level exposure.

  4. SIP Intelligence & 30-Day Liquidity Calendar:

    • Verified vs Auto-Detected Mandates: Statement ingestion automatically detects recurring monthly debit patterns. You can review and promote inferred schedules to verified mandates with a 1-tap "Confirm" toggle, or pause/resume existing mandates.
    • Mandate Management on Fund Details: View and toggle the SIP mandate status directly from any individual fund's detail page.
    • 30-Day Cash Flow Matching: Matches upcoming SIP execution dates against your primary liquid bank balance, flagging projected shortfalls before auto-debits bounce.
    • Step-Up Wealth Simulator: Simulates 10-year wealth projections with 0%, 5%, 10%, and 15% annual step-up multipliers to demonstrate compounding impact.

  5. Peer Benchmarking & Alpha-Beta Risk Matrix:

    • Risk-Return Quadrant Matrix: Interactive visual plot mapping each fund across 4 distinct risk-return zones:
      • ⭐ Star Outperformer: High Alpha ($\alpha > 0$), Low Beta ($\beta < 1.0$) — Ideal capital efficiency.
      • 🚀 Aggressive Alpha: High Alpha ($\alpha > 0$), High Beta ($\beta \ge 1.0$) — Market-beating with active volatility.
      • 🛡️ Defensive Value: Subdued Alpha ($\alpha \le 0$), Low Beta ($\beta < 1.0$) — Capital preservation profile.
      • ⚠️ High Risk Lagging: Negative Alpha ($\alpha < 0$), High Beta ($\beta \ge 1.0$) — Sub-optimal risk/return tradeoff.
    • Anchor Portfolio Indicator: Displays a glowing target node representing your overall consolidated portfolio coordinates $(\alpha, \beta)$ alongside an automated executive posture takeaway banner.
    • Category Benchmark Comparison: Fund 1Y return vs official Total Returns Index (TRI) benchmark bars, Sharpe ratio, and quartile rankings (Q1 to Q4).
    • AI Advisor Comprehensive Report: Section 16.1 advisory intelligence review with structured sections for Executive Summary, Recommended Moves, Alpha Opportunities, and Risk Guardrails.

  6. Family Member Filter Integration:

    • Selecting any family member from the top navigation bar dynamically recalculates and filters all 5 intelligence modules for that specific member.
    • Selecting "All Members" consolidates all family portfolios into a single household-wide analytical view. Child accounts are automatically restricted to their own holdings.

❓ Troubleshooting & FAQ ​

  • "I deleted a transaction but my portfolio value didn't change!"
    • Check Recalculation: The dashboard usually updates instantly, but complex portfolios may require a manual "Recalculate Holdings" from the settings to force a full cost-basis audit.
  • "My Average Cost looks incorrect."
    • Root Cause: Often caused by a missing historical buy order or a duplicate CAMS entry. Use the Deep-Dive historical grid to find the anomaly and correct the individual order's units/NAV.
  • "I see a 'Not in Portfolio' error after deleting a transaction."
    • Recovery: WealthFam uses Identity-Stable In-Place Updates. If you delete the last transaction of a holding, the holding becomes empty and is removed from the active view. The internal ID is preserved, so if you add a new transaction later, your historical links (Goals) will reactivate automatically.
  • "What does 'Soft-Delete' mean for my data?"
    • Audit Trail: Your data is never permanently wiped. It is hidden from the active frontend and reporting engines but remains in the database with a deletion timestamp. This allows for forensic recovery and historical parity auditing.

⚠️ 9. Budget Management ​

Creating Budgets ​

  1. Navigate to Budgets from the sidebar.
  2. Click Add Budget and select a category.
  3. Enter the monthly spending limit (₹).
  4. Create an OVERALL budget for total family spending.

Understanding Budget Alerts ​

WealthFam proactively monitors your spending and sends real-time alerts:

  • 80% (Info) 🟡: "You are approaching your limit. Moderate discretionary spending."
  • 100% (Warning) 🟠: "Your limit has been reached."
  • 120% (Breach) 🔴: "Significant overspending detected."

These alerts are delivered via:

  • WebSocket to connected web/mobile clients (instant).
  • Push notification on Android (via foreground service).

Hierarchical Budgets ​

Parent-level budgets automatically include spending from sub-categories. For example:

  • Budget on "Food" ← includes all spending under "Dining Out", "Groceries", "Delivery".
  • No manual aggregation needed; the system handles rollup automatically.

Budget History & Forecast ​

  • Budget History Chart: View month-by-month spending trends for each category.
  • Spending Forecast: See projected end-of-month spending based on your current daily velocity.

🛡️ 15. Privacy & Security ​

Masking Mode ​

  • Use Case: Before reviewing financials in public or sharing your screen.
  • How: Toggle the Eye Icon (masking mode) or use the "Toggle Mask" button on the Android foreground service notification.
  • Effect: All absolute currency values are obfuscated (multiplied by a large factor). Percentage-based analytics and chart trends remain intact.

Member Privacy ​

  • Tenant Admins (OWNER role) can view aggregate family data and individual budgets.
  • Admins cannot see granular private transaction notes of other "Adult" members unless explicitly shared.
  • Child role members only see their personal goals and limited dashboard data.

Device Authorization ​

  • Every new mobile device generates a unique Hardware ID.
  • Navigate to Settings → Devices to see all registered devices.
  • Admin must approve each device before it can submit SMS transaction data.

Session Security ​

  • JWT tokens are tracked via per-session JTI in the UserToken table.
  • Expired and revoked tokens are automatically pruned daily at 03:00 UTC.
  • Multiple devices can maintain independent sessions.

🔄 16. Recurring Transactions ​

Setting Up Recurring Bills ​

  1. Navigate to Insights → Recurring tab.
  2. Click Add Recurring and fill in:
    • Name: e.g., "Netflix", "Electricity Bill".
    • Amount and Type (Debit/Credit).
    • Frequency: Daily, Weekly, Bi-Weekly, Monthly, Quarterly, Yearly.
    • Start Date and Account.
    • Category (optional).
  3. The system automatically generates transactions on the scheduled dates.

How Auto-Generation Works ​

  • The daily_recurrence_check runs every day at 00:01 UTC.
  • It scans all RecurringTransaction records where next_run_date <= now and is_active == True.
  • For each match, a transaction is created and next_run_date is advanced by the frequency.
  • Dashboard shows upcoming bills for the next 30 days.

📱 17. Mobile-Specific Features ​

Consolidated Dashboard API ​

The mobile app uses a single get_consolidated_dashboard() API call that returns:

  • Summary metrics (today, yesterday, monthly totals).

  • Recent transactions.
  • Triage count. This minimizes network round-trips for a smooth mobile experience.

🗂️ 18. Categories & Rules ​

Managing Categories ​

  1. Go to Categories from the sidebar (Web) or Categories Management (Mobile).
  2. Create categories with:
    • Name: e.g., "Food", "Transport", "Shopping".
    • Icon: Emoji representation.
    • Color: Hex color code.
    • Type: Expense or Income.
    • Parent: Optional — create sub-categories (e.g., "Dining Out" under "Food").

Auto-Categorization Rules ​

  1. Go to Categories → Category Rules.
  2. Create Category Rules:
    • Name: Rule identifier (e.g., "Food Apps").
    • Keywords: Matching strings (e.g., ["Zomato", "Swiggy"]).
    • Category: Target category to assign.
    • Priority: Higher priority rules execute first.
    • Is Transfer: Mark as transfer rule with destination account.
    • Exclude from Reports: Auto-exclude matched transactions.

Reporting Unrecognized Alerts (Help Improve Extraction) ​

  1. Open Settings → Ingestions on Web or Ingestions (and Unrecognized Alerts) on Mobile.
  2. Locate an SMS or Email labeled Could Not Extract / Unrecognized Alert.
  3. Click Report Anonymized to inspect the scrubbed preview (which masks account digits, personal numbers, and amounts).
  4. Review and confirm consent, then submit to help improve automatic bank alert coverage.

🏷️ 19. Merchant Alias Management ​

Creating an Alias ​

  1. Navigate to Categories → Category Rules → Merchant Aliases (or trigger rename from Transactions).
  2. Click New Alias.
  3. Enter the Raw Text Pattern (the noisy text from the bank, e.g., AMZN MKTP) and the Clean Merchant Name (e.g., Amazon).

Retroactive Updates ​

  • When saving an alias, check "Apply to existing transactions?".
  • WealthFam previews how many ledger and triage transactions match before scanning history and renaming them automatically across SMS, Email, PDF Statements, and CSV imports.

📋 20. Ingestion Activity & Ignore Control ​

Monitoring SMS & Email Ingestions ​

  1. Go to Settings → Ingestions (Web) or open Ingestions → Ingestion Activity (Mobile).
  2. Filter by Date Range (defaulting to Today, with presets for Yesterday, Last 7 Days, Last 30 Days, This Month, All Time, or custom dates), Person, Source (All Sources, SMS, Email), Device / Mailbox, Account, Outcome, or full-text Search.
  3. Click View Content on any row to expand the full SMS or Email body and see the plain-language outcome (Added to Ledger, Needs Review, Account Not Linked, Duplicate Skipped, Ignored by Rule, Non-Financial / OTP, or Unrecognized Alert) alongside direct action links.

Ignoring Senders & Re-Allowing Later ​

  1. On any SMS or Email row in Settings → Ingestions, click Ignore (or Ignore in Future on Mobile) to match by sender, subject phrase, or body/filename keyword and channel (SMS, EMAIL, STATEMENT / Email Statements (PDF), or ALL).
  2. Future matching messages (or email .pdf statement attachments for STATEMENT) are discarded immediately before processing while remaining visible under the Ignored by Rule outcome for SMS/Email.
  3. Click Allow directly on an ignored row or inside the Ignored Rules modal to stop blocking that sender/keyword at any time. Statement PDF ignore rules can also be managed directly from Banking → Statements → Ignored Rules on Web or by choosing Email Statements (PDF) in Mobile Ingestions.

🏦 21. Auto-Account Discovery ​

How to use Auto-Discovery ​

  1. When a transaction arrives for an unknown account, WealthFam creates a "Detected" account (e.g., Detected: SMS (XX1234)).
  2. Navigate to Settings → Accounts.
  3. Find the account marked with the "Unverified" badge.
  4. Click Edit, provide a proper name (e.g., "HDFC Savings"), and click Verify.
  5. All future transactions for this mask will now map to your verified account.

🛠️ 22. Deep How-To: Advanced Workflows ​

How to Handle Split Transactions ​

Often, a single bank transaction represents multiple categories (e.g., a Grocery store bill that includes Food and Home Supplies).

  1. Open the transaction in the Transaction Modal.
  2. Click Split Transaction.
  3. Add rows for each sub-category and assign amounts.
  4. The sum must match the total transaction amount.
  5. Result: Your parent ledger remains accurate, but reports will show the split breakdown.

How to Master Categorization Rules ​

To automate your financial life, use prioritized keywords.

  1. Go to Categories → Category Rules.
  2. Standard Rule: keywords: ["Amazon", "Flipkart"] → Category: Shopping.
  3. High-Priority Exception: keywords: ["Amazon Cloud", "AWS"] → Category: Education/Work (Set Priority to 10).
  4. Order Matters: The system evaluates rules in descending order of priority. Always set specialized rules higher than generic ones.

How to Perform a "Portfolio Migration" ​

If you are moving from another app to WealthFam:

  1. Export your data as CSV.
  2. Go to WealthHub → Settings → Tools → Importer.
  3. Map your columns to the WealthFam schema.
  4. Use the Preview Mode to catch mapping errors before final ingestion.

⚡ 23. Attention Hub & Action Required Center ​

The Attention Hub gives you a single place to review all pending decisions, deadlines, and anomalies across your household finances.

Web Dashboard ​

  1. Look at the top navigation bar for the Bell icon. When actions are pending, it displays an amber badge count: 🔔 {N}.
    • If pulsing, items require your review.
    • If it reads Caught up, all statements, debts, and transactions are reconciled.
  2. Click the pill to open the Action Required drawer.
  3. Click any action item to jump directly to its screen (e.g. Card Due opens the specific Credit Card, Budget Breach opens the over-limit Category, etc.).
  4. Switch to the Notifications tab to view real-time WebSocket alerts and milestones.

Mobile App (Android) ​

  1. On the main Dashboard, a dedicated ACTION row appears directly below your Monthly Overview hero card whenever actions are pending.
  2. The row displays quick-action chips with live counters:
    • Review Transactions: Opens unverified SMS/Email transactions for 1-tap categorization.
    • Statements: Shows parsed statements requiring review or password unlock.
    • Transfers: Jump to Transfers Hub to confirm detected account transfers.
    • Cards Due: Highlights credit cards with bills due in $\le 5$ days or overdue.
    • Over Budget: Direct link to categories exceeding your monthly spending cap.
    • EMIs Due: Alerts when loan installment dates are approaching.
    • Recurring Found: Review automated recurring subscription detections.
    • Low Balance: Warns if savings accounts dip below minimum balance thresholds.
    • Update CAS: Reminds you when mutual fund valuations are $> 30$ days old.
  3. When all items are attended, the row automatically collapses to zero height.

Marking Statements as Attended ​

  1. Go to Statements (Web or Mobile).
  2. Unattended parsed statements display an amber Needs Review badge.
  3. After reviewing transactions, tap "Mark Attended".
    • If all transactions are reconciled, it marks attended immediately.
    • If unreconciled transactions remain, a warning dialog prompts for your confirmation.
  4. You can tap "Reopen" at any time to return the statement to the review queue.
  5. Reprocessing a statement via POST /statements/{id}/reprocess automatically resets it to is_attended = False.
