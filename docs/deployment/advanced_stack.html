🏗️ Advanced Modular Stack Deployment ​

The WealthFam Advanced Stack is the definitive orchestration pattern for production environments. Unlike the monolithic single-container setup, this stack decouples the Backend, WebApp, and Parser into independent microservices.

💎 Why Choose Modular? ​

  • Isolated Scaling: Scale the parser independently to handle high-volume SMS/Email ingestion.
  • Fault Isolation: A crash in the front-end Nginx won't affect the back-end AI processing.
  • CI/CD Parity: Each repository has its own GitHub Action pushing to the wglabz namespace on Docker Hub.
  • Dedicated Port Management: Fine-grained control over exposure for each service.

🏗️ The Orchestration Blueprint ​

The stack is managed via a unified docker-compose.yml located in the Infra/advanced-stack/ directory.

🌐 Internal Networking ​

The services communicate over an isolated bridge network:

  • wglabz-net: Private network for inter-container traffic.
  • DNS & REST Resolution: The consumer WebApp proxies /api and /ws/ strictly to http://backend:8000 (with zero direct /parser exposure). backend talks internally to http://parser:8001 (PARSER_SERVICE_URL) and proxies anonymized training previews/samples to http://admin-backend:8002 (ADMIN_SERVICE_URL), admin-web proxies /admin-api/ to http://admin-backend:8002/v1/, and admin-backend communicates with backend and parser strictly via REST.

📊 Data Persistence & Security Context ​

The microservices utilize shared /data and PostgreSQL storage layouts under hardened, unprivileged execution:

  • wglabz-data volume: Mounted to /data across containers (user: "10001:10001"). Used by parser (ingestion_engine_parser.duckdb), admin-backend (telemetry.duckdb & /data/logos/), and backend (/data/vault/, /data/logos/, and /data/backups/).
  • wglabz-pgdata volume: Managed exclusively by db for backend (wealthfam ledger + brand_logos).
  • Non-Root Execution: Microservice containers run as dedicated unprivileged appuser:appgroup (10001:10001), and WebApp/Admin-Web run as unprivileged nginx (101:101).
  • Automated Snapshots: Daily disaster recovery backup routine runs automatically at 03:30 UTC via APScheduler, creating compressed archives with SHA-256 manifests in /data/backups.

🚀 Deployment Guide ​

1. Prerequisites ​

  • Docker & Docker Compose installed.
  • Repositories created on Docker Hub under the wglabz organization.

2. Configuration (.env) ​

Create a .env file in Infra/advanced-stack/ with the following:

properties
SECRET_KEY=yoursecretkey
DOCKER_ORG=wglabz

3. Launching the Hub ​

Run the following command from the root of the ecosystem:

bash
docker compose -f Infra/advanced-stack/docker-compose.yml up -d
