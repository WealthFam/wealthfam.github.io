🏗️ Build, Release & Local Push Infrastructure ​

WealthFam operates a multi-repository workspace orchestrated via the Infra repository. This document details the CLI tooling, multi-repo release workflow, Docker Buildx pipeline, and local deployment infrastructure.

🧭 Multi-Repo Architecture & Tooling ​

The WealthFam ecosystem spans several distinct repositories:

  • Backend: FastAPI core engine & financial ledger
  • Web-App: Vue 3 + Vite frontend dashboard
  • Parser: Ingestion microservice & pattern engine
  • Admin-Backend: FastAPI telemetry, endpoint SLA, parser studio & brand logo API (:8002)
  • Admin-Web: Vue 3 + Vite enterprise admin console (:8080 / :5174)
  • Mobile-App: Flutter Android client
  • Infra: Container orchestration, build scripts, and CLI tooling
  • Docs: VitePress documentation hub

Unified Workspace CLI (wf.sh) ​

At the workspace root (or within Infra/), the wf.sh command provides an interactive, menu-driven CLI for all lifecycle operations:

bash
./Infra/wf.sh [command]
CommandActionImplementation
./Infra/wf.sh statusScans git branch status and uncommitted changes across all sub-reposInfra/scripts/cli/status.sh
./Infra/wf.sh syncPulls latest changes across all local repositoriesInfra/scripts/cli/sync.sh
./Infra/wf.sh devLaunches local development services (Backend, Frontend, Parser)Infra/scripts/cli/dev.sh
./Infra/wf.sh testRuns comprehensive test suites across Backend, Mobile, and WebInfra/scripts/cli/test.sh
./Infra/wf.sh releasePre-flight check, version bumping, git commit/tag, and multi-repo pushInfra/scripts/cli/release.sh

🚀 Release Management Pipeline (release.sh) ​

The release workflow guarantees cross-repository synchronization and atomic version bumping:

  1. Pre-Flight Scans: Discovers all active sub-repos and flags untracked/uncommitted changes.
  2. Version Governance (version.json):
    • Semantic versioning: major.minor.patch
    • Build string format: v<MAJOR>.<MINOR>.<PATCH>-b<GIT_HASH>-<YYYYMMDD>
  3. Automated Testing: Runs unit tests and linter pre-flights before tagging.
  4. Multi-Repo Tagging & Push: Commits changes with structured release notes, tags the commit, and pushes to remote origins.

🐳 Docker Multi-Arch Buildx Pipeline (build_and_push.sh) ​

Located at Infra/scripts/deploy/build_and_push.sh, this script builds unified, production-grade container images supporting both linux/amd64 (cloud/server) and linux/arm64 (Raspberry Pi, Apple Silicon, ARM NAS).

Execution ​

bash
bash Infra/scripts/deploy/build_and_push.sh

Build Process Workflow ​

  1. Environment Detection: Resolves workspace directories (Backend, Parser, Web-App, Admin-Backend, Admin-Web, Infra/docker/Dockerfile).
  2. Tag Generation:
    • Queries Infra/version.json for major, minor, patch versions.
    • Extracts current Git SHA and date.
    • Generates dual tags: wglabz/wealthfam:v<VERSION>-b<HASH>-<DATE> and wglabz/wealthfam:latest.
  3. Multi-Architecture Build (docker buildx):
    • Creates/reuses the wealthfam-builder containerized builder instance:
      bash
      docker buildx create --name wealthfam-builder --use --driver docker-container
    • Invokes docker buildx build --platform linux/amd64,linux/arm64 --push to compile and push directly to Docker Hub.

🏠 Local Push & Server Deployment (deploy_to_pi.sh) ​

For self-hosters deploying to local servers (e.g. Raspberry Pi, Unraid, TrueNAS, Home Server):

bash
bash Infra/scripts/deploy/deploy_to_pi.sh [PI_HOST]

What It Does: ​

  1. Verifies SSH connectivity to the target host.
  2. Syncs docker-compose.yml, environment configurations, and persistent volume definitions.
  3. Pulls the latest multi-arch Docker image matching the target hardware architecture (linux/arm64 or linux/amd64).
  4. Performs zero-downtime container recreation:
    bash
    docker-compose pull
docker-compose up -d --remove-orphans
  5. Executes automated health checks against /health and /api/v1/health.
