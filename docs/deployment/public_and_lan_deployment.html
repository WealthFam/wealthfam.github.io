🌐 Production & Local LAN Deployment Guide ​

This guide provides step-by-step runbooks for deploying WealthFam across all three supported hosting topologies:

  1. Local LAN IP (Home Server / Raspberry Pi — no domain required)
  2. Public Internet with Custom Domain (Automatic Let's Encrypt HTTPS + HSTS via Caddy)
  3. Home Server with HTTPS & Zero Port-Forwarding (Tailscale HTTPS or Cloudflare Tunnel — enables Release Mobile APK & Browser WebCrypto)

1. Prerequisites & One-Time Secret Generation ​

Both the Monolith (Infra/docker/docker-compose.yml) and Individual Images (Infra/advanced-stack/docker-compose.yml) stacks enforce fail-closed startup in ENVIRONMENT=production.

Generate your required cryptographic secrets (never reuse the same string across variables):

bash
echo "POSTGRES_PASSWORD=$(openssl rand -hex 24)"
echo "SECRET_KEY=$(openssl rand -hex 32)"
echo "BLIND_INDEX_SALT=$(openssl rand -hex 32)"
echo "ADMIN_SECRET_KEY=$(openssl rand -hex 32)"
echo "ADMIN_PASSWORD=$(openssl rand -hex 16)"

CAUTION

Back up SECRET_KEY and BLIND_INDEX_SALT securely in a password manager. Rotating BLIND_INDEX_SALT requires re-computing blind indexes; rotating SECRET_KEY requires placing the old key in PREVIOUS_SECRET_KEYS.

2. Scenario A: Local LAN IP Deployment (e.g. 192.168.0.7) ​

Option A1 — Monolith Container ​

bash
cd Infra/docker
cp .env.example .env

Edit Infra/docker/.env:

env
ENVIRONMENT=production
ALLOWED_ORIGINS=http://192.168.0.7
ALLOW_PUBLIC_REGISTRATION=true   # set to false after creating your family accounts
TENANT_SEAL_STRICT=true
RATE_LIMIT_ENABLED=true
POSTGRES_USER=wealthfam
POSTGRES_PASSWORD=<generated>
POSTGRES_DB=wealthfam
SECRET_KEY=<generated>
BLIND_INDEX_SALT=<generated>
ADMIN_SECRET_KEY=<generated>
ADMIN_USERNAME=admin
ADMIN_PASSWORD=<generated>

Start the stack:

bash
docker compose -f Infra/docker/docker-compose.yml up -d

Option A2 — Individual Microservice Images (Recommended for Stronger Isolation) ​

bash
cd Infra/advanced-stack
cp .env.example .env
# Fill in the same secrets & ALLOWED_ORIGINS=http://192.168.0.7
docker compose -f Infra/advanced-stack/docker-compose.yml up -d
  • Web-App: http://192.168.0.7
  • Admin-Web (loopback-only for security):
    bash
    ssh -L 8080:127.0.0.1:8080 user@192.168.0.7
# Open http://localhost:8080 on your laptop
  • LAN HTTP Caveat: Web-App login and server-side encryption (AES-256-GCM + VaultFileCipher v2) work 100% over plain HTTP. However, Release Android APKs and browser WebCrypto (useZkVault) require HTTPS (see Scenario B or C).

3. Scenario B: Public Internet Deployment (Domain + Automatic HTTPS) ​

  1. DNS: Point an A (and optionally AAAA) record for app.yourdomain.com to your server's public IP.
  2. Firewall: Open only ports 80/tcp, 443/tcp, and 443/udp (HTTP/3). Keep 5432, 8000, 8001, 8002, and 8080 closed on the firewall.
  3. Configure .env in Infra/docker/.env:
    env
    ENVIRONMENT=production
DOMAIN=app.yourdomain.com
ALLOWED_ORIGINS=https://app.yourdomain.com
ALLOW_PUBLIC_REGISTRATION=true   # flip to false immediately after registering your family
TENANT_SEAL_STRICT=true
RATE_LIMIT_ENABLED=true
# ... plus your 5 generated secrets
  4. Launch with the Caddy TLS Overlay:
    bash
    docker compose -f Infra/docker/docker-compose.yml -f Infra/docker/docker-compose.tls.yml up -d
    Caddy automatically provisions and renews Let's Encrypt TLS certificates, enforces HSTS, and proxies HTTPS traffic to wealthfam:80.
  5. Lock Down Registration: Once your family OWNER account is created, set ALLOW_PUBLIC_REGISTRATION=false in .env and restart:
    bash
    docker compose -f Infra/docker/docker-compose.yml -f Infra/docker/docker-compose.tls.yml up -d --force-recreate wealthfam

4. Scenario C: Home Server with Real HTTPS & Zero Port-Forwarding ​

If you run WealthFam at home (behind CGNAT or without opening router ports) and want Release Mobile APKs + Browser WebCrypto to work seamlessly:

Option C1 — Tailscale HTTPS (Private to Your Devices) ​

bash
# On the host running WealthFam on port 80:
tailscale serve --bg http://127.0.0.1:80

Set ALLOWED_ORIGINS=https://<machine>.<tailnet>.ts.net in .env and point WealthFam Mobile to https://<machine>.<tailnet>.ts.net.

Option C2 — Cloudflare Tunnel (Public HTTPS, No Open Ports) ​

Create a Cloudflare Tunnel pointing https://app.yourdomain.com to http://127.0.0.1:80, and set ALLOWED_ORIGINS=https://app.yourdomain.com in .env.

5. Post-Upgrade Encryption Backfill & Verification ​

If upgrading an existing installation that had pre-encryption plaintext rows or Vault documents/thumbnails:

bash
# 1. Dry-run preview (Monolith container name: wealthfam; Advanced Stack: wglabz-backend)
docker exec -it wealthfam python /app/scripts/encrypt_legacy_data.py --dry-run

# 2. Execute live idempotent backfill
docker exec -it wealthfam python /app/scripts/encrypt_legacy_data.py

# 3. Verify automated backup integrity (dry-run SHA-256 check)
docker exec -it wealthfam python /app/scripts/restore.py --archive /data/backups/<latest>.tar.gz --dry-run
