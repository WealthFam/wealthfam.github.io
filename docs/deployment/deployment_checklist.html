📋 Sovereign Deployment Checklist ​

Use this checklist to ensure your WealthFam instance is properly orchestrated for privacy-first financial engineering.

Pre-Deployment ​

Repository Setup ​

  • [ ] Required repositories are cloned locally (Infra, Backend, Parser, Frontend).
  • [ ] Infrastructure blueprints are ready in Infra/docker.
  • [ ] .env is configured with a secure SECRET_KEY.

Docker Environment ​

  • [ ] Docker and Docker Compose installed (v2.0+ recommended).
  • [ ] Sufficient disk space for database volumes (PostgreSQL and DuckDB; 1GB+ recommended for start).
  • [ ] Port 80 (or your chosen internal port) is available.

Deployment Stages ​

Stage 1: Local Orchestration (Docker) ​

  • [ ] docker-compose up -d executed from Infra/docker.
  • [ ] All 3 core services (Backend, Parser, Frontend) are running.
  • [ ] Health endpoint responds: curl http://localhost/health.
  • [ ] Database files/containers are active and schema migrations have succeeded.

Stage 2: Mobile Connectivity ​

  • [ ] Latest APK installed on Android device.
  • [ ] Server URL set to local IP (e.g., http://192.168.1.100).
  • [ ] SMS permissions granted.
  • [ ] Device authorized in Web UI → Settings → Devices.

Post-Deployment Verification ​

Precision Integrity ​

  • [ ] Can register the primary Family Owner account.
  • [ ] Transaction Triage queue loads correctly.
  • [ ] AI Insights generate (if GEMINI_API_KEY is set).

Security & Privacy ​

  • [ ] Masking Mode verified (Eye icon obfuscates values).
  • [ ] Background SMS service shows persistent notification.
  • [ ] No external traffic except to authorized endpoints (Gemini, IMAP).

Maintenance ​

Backup Strategy ​

  • [ ] Automated backup job verified (BACKUP_ENABLED=true, runs daily at 03:30 UTC via APScheduler).
  • [ ] Manual ecosystem backup routine tested: python Infra/scripts/maintenance/backup.py --output-dir /data/backups.
  • [ ] Restoration dry-run verified: python Infra/scripts/maintenance/restore.py --archive /data/backups/<snapshot>.tar.gz --dry-run.
  • [ ] Off-site backup sync (e.g., Encrypted Cloud Storage or NAS sync of /data/backups) verified.

Updates ​

  • [ ] git pull on Infra repo for latest orchestration logic.
  • [ ] docker-compose pull to fetch latest microservice images.
  • [ ] docker-compose up -d to apply updates with zero downtime objective.

🆘 Troubleshooting ​

  • [ ] Check logs: docker-compose logs -f.
  • [ ] Verify database permissions: ls -la ./data.
  • [ ] Refer to the Full Deployment Guide.
  • [ ] Join the Discord Community.
