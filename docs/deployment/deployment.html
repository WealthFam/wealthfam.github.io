🚀 System Deployment & Hosting Guide ​

WealthFam is a sophisticated, containerized microservice ecosystem. To maintain the highest standards of data integrity and privacy (the Sovereign Circle model), we have refined our deployment pathways.

🏛️ Deployment Strategy ​

WealthFam is built for privacy-first local hosting. We provide an official demo for exploration, but for personal use, local orchestration is the mandatory path until our SaaS offering is launched.

1. 🌐 Official Live Demo ​

The only authorized cloud instance of WealthFam is hosted on Render. This instance is for evaluation purposes.

  • Demo Instance: https://wealthfam.onrender.com
  • Deployment Status: 🟢 Operational (Render Free Tier)
  • Test Credentials:
    • Username: demo@demo.com
    • Password: demo123

WARNING

The demo database is ephemeral and resets periodically. Do not input real sensitive financial data into the demo instance.

2. 🐳 Local Hosting (Docker) ​

For your personal data, we support local hosting via Docker. This ensures your data never leaves your hardware.

bash
# 1. Pull the official orchestration stack
git clone https://github.com/WealthFam/Infra.git
cd Infra/docker

# 2. Configure your environment (Optional)
# Edit .env to set your GEMINI_API_KEY for AI features

# 3. Launch the ecosystem
docker-compose up -d

Hardware Recommendation:

  • Entry: Raspberry Pi 4 (4GB+)
  • Optimal: Dedicated NAS or Home Server (8GB+ RAM, SSD)

📅 Roadmap: Managed Hosting (SaaS) ​

We recognize that not every user wants to maintain their own hardware. We are in the final stages of architecting the WealthFam Cloud (SaaS).

  • Status: 🛠️ In Development (Alpha)
  • Features:
    • Automated Backups
    • Managed Security Updates
    • 100% Privacy via Encrypted Storage Volumes (PostgreSQL/DuckDB)
    • Multi-tenant isolation

Whether running locally or in development, the environment is controlled via these primary variables:

📱 Mobile Connectivity ​

To connect your mobile device to your local instance:

  1. Ensure your phone is on the same network or you have a secure VPN/Tunnel (e.g., Tailscale).
  2. Open WealthFam Mobile → Settings.
  3. Point the URL to your local server IP (e.g., http://192.168.1.100:80).
  4. Login with your local account.
