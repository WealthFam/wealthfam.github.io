⚡ Quick Deployment Reference ​

Technical cheat sheet for orchestrating the WealthFam ecosystem.

🐳 Docker Compose (Sovereign) ​

Run from the Infra/docker directory:

bash
# Start all services
docker-compose up -d

# View real-time logs
docker-compose logs -f

# Specific service logs
docker-compose logs -f backend
docker-compose logs -f parser

# Restart system
docker-compose restart

🔑 Environment Variables ​

The core configuration for your Sovereign Circle.

bash
# Database & File Persistence
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/wealthfam
PARSER_SERVICE_URL=http://localhost:8001/v1
TELEMETRY_DATABASE_URL=duckdb:////data/telemetry.duckdb
LOGOS_STORAGE_PATH=/data/logos
VAULT_STORAGE_PATH=/data/vault
ADMIN_USERNAME=admin
ADMIN_PASSWORD=change_me_in_prod
ADMIN_SECRET_KEY=$(openssl rand -hex 32)

# Environment & Security
ENVIRONMENT=development
SECRET_KEY=$(openssl rand -hex 32)
PREVIOUS_SECRET_KEYS=
ALLOWED_ORIGINS=*

# AI Intelligence (Gemini)
GEMINI_API_KEY=your_api_key_here

# AI Agent Optimization (Optional)
# Set to 'true' to disable the heavy AI Agent service in resource-constrained environments (e.g. Render Free Tier)
DISABLE_AI_AGENT=false
VITE_DISABLE_AI_AGENT=false

💾 Backup & Maintenance ​

Snapshotting the Ledger, DuckDBs & Document Vault ​

bash
# Backup PostgreSQL database
docker exec -t wealthfam-db pg_dump -U postgres wealthfam > ./backups/wealthfam_$(date +%Y%m%d).sql

# Backup Parser & Admin Telemetry DuckDB files
docker cp wglabz-parser:/data/ingestion_engine_parser.duckdb ./backups/parser_$(date +%Y%m%d).duckdb
docker cp wglabz-admin:/data/telemetry.duckdb ./backups/telemetry_$(date +%Y%m%d).duckdb

# Backup persistent Document Vault (/data/vault)
docker cp wglabz-backend:/data/vault ./backups/vault_$(date +%Y%m%d)
