🧭 UI/UX Design Guide ​

Vue 3 + Vuetify 3 + Material Design (Personal Finance App) ​

🎯 Core Principles ​

  • Consistency > creativity
  • Reuse > rebuild
  • System-driven UI (theme + tokens)
  • Mobile-first, responsive by default
  • Data clarity over visual noise

🎨 Theme Rules (STRICT) ​

  • All colors must come from Vuetify theme (primary, secondary, surface, error, etc.)

  • ❌ No hex (#fff) or rgb in components

  • ❌ No inline color styling

  • ✅ Use semantic meaning:

    • primary → main actions
    • success → income
    • error → expense
    • warning → pending/alerts

🧩 Design Tokens (Centralized) ​

Create: src/design/tokens.ts

ts
export const spacing = {
  xs: '4px',
  sm: '8px',
  md: '16px',
  lg: '24px',
  xl: '32px'
}

export const radius = {
  sm: '4px',
  md: '8px',
  lg: '16px'
}

📐 Layout System ​

Grid Rules ​

  • Use v-container, v-row, v-col ONLY
  • Follow 12-column grid

Responsive Columns ​

  • Mobile: 1 column
  • Tablet: 2–6 columns
  • Desktop: 12 columns

Page Padding ​

  • Mobile: pa-2
  • Tablet: pa-4
  • Desktop: pa-6

📱 Responsive Rules ​

  • Always design mobile-first

  • Use Vuetify display helpers:

    • hidden-sm-and-down
    • hidden-md-and-up

Breakpoints Behavior ​

ScreenLayout
MobileStacked
TabletPartial grid
DesktopFull grid

🔤 Typography ​

  • Use Material typography ONLY:

    • text-h1 → text-h6
    • text-body-1, text-body-2
    • text-caption

  • ❌ No custom font sizes

  • ❌ No inline font styling

Usage Rules ​

  • Page title → text-h5
  • Section title → text-h6
  • Card title → text-subtitle-1
  • Metadata → text-caption

🧱 Component Standards ​

🔘 Buttons (v-btn) ​

  • Variants:

    • flat (default)
    • tonal (secondary)

  • Sizes:

    • default or small

Rules:

  • One primary action per section
  • Avoid more than 2 buttons inline

🧾 Cards (v-card) ​

  • Use:

    • rounded="lg"
    • pa-4 or pa-6

Rules:

  • Wrap major UI blocks
  • Avoid nesting >2 levels

✏️ Inputs ​

  • Use:

    • variant="outlined"
    • density="comfortable"

Rules:

  • Labels always visible
  • Always show validation messages

📊 Tables ​

  • Use v-data-table

Must support:

  • sorting
  • filtering
  • pagination

Rules:

  • Right-align numeric values

  • Use semantic colors:

    • income → success
    • expense → error

📈 Charts ​

  • Keep minimal and clean

  • Avoid heavy gradients

  • Maintain consistent colors:

    • income → green
    • expense → red

🧠 UX Rules (Finance-Specific) ​

  • Always display currency symbol (₹)

  • Never hide critical numbers

  • Show:

    • summary first
    • details below

Standard Layout ​

[ Balance Summary ]
[ Charts ]
[ Transactions Table ]

🚫 Forbidden (STRICT) ​

  • ❌ Inline styles (style="")
  • ❌ Random pixel values (e.g., margin: 13px)
  • ❌ Hardcoded colors
  • ❌ Deep nesting (>3 levels)
  • ❌ Mixing UI libraries

🧩 Vuetify Configuration (MANDATORY) ​

Centralize in vuetify.ts

ts
createVuetify({
  theme: {
    defaultTheme: 'light',
    themes: {
      light: {
        colors: {
          primary: '#1976D2',
          success: '#2E7D32',
          error: '#D32F2F'
        }
      }
    }
  },
  defaults: {
    VBtn: {
      variant: 'flat'
    },
    VCard: {
      rounded: 'lg'
    },
    VTextField: {
      variant: 'outlined',
      density: 'comfortable'
    }
  }
})

🧪 Code Quality Rules ​

  • Use composables for logic

  • Keep components < 300 lines

  • Separate:

    • UI
    • business logic
    • API

🧠 Naming Conventions ​

  • Base* → reusable UI (BaseCard, BaseButton)
  • App* → layout components
  • Feature* → domain components

⚡ Recommended Base Components ​

  • BaseCard.vue
  • BasePage.vue
  • BaseTable.vue

🤖 AI / Antigravity Instruction ​

Follow UI_GUIDE.md strictly. Do not introduce styles, spacing, or colors outside the defined system. Use Vuetify components and defaults. Maintain responsive Material Design layout.
