# WealthFam Landing Page

The official marketing and informational landing page for the WealthFam ecosystem.

## 🚀 Overview

This repository hosts the public-facing website at [wealthfam.github.io](https://wealthfam.github.io). It is built with high-fidelity aesthetics to showcase the platform's capabilities to potential users and developers.

## 🛠️ Tech Stack

- **HTML5/CSS3**: Clean, semantic structure.
- **Vanilla JavaScript**: Lightweight interactions.
- **Tailwind CSS (CDN)**: Modern, utility-first styling.
- **Lucide Icons**: Consistent iconography with the main app.
- **Intersection Observer API**: For smooth scroll-based animations.

## 📁 Structure

- `index.html`: Main entry point.
- `assets/`: 
  - `hero.png`: High-resolution landing visualization.
  - `logo.png` & `wordmark.png`: Brand assets.
- `css/style.css`: Custom animations and overrides.
- `js/main.js`: Interaction logic.

## 🌐 Deployment
This site is hosted via **GitHub Pages**. Simply push to the `main` branch to update the live site.
