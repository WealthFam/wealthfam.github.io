## 🚀 Overview

This repository hosts the public-facing landing page for WealthFam. Built with a focus on modern aesthetics, responsiveness, and performance, it serves as the primary onboarding point for users and the gateway to our technical documentation.

---

## 🎨 Visual Identity

| Asset | Description |
| :--- | :--- |
| **`index.html`** | The master entry point with custom glassmorphism and animations. |
| **`assets/hero.png`** | AI-generated "Technical Blueprint" hero visualization. |
| **`assets/logo.png`** | The signature WealthFam Ruby & Emerald emblem. |

---

## 🛠️ Tech Stack

- **Foundational**: Semantic HTML5 & CSS3.
- **Styling**: Tailwind CSS (Lucid-accented variations).
- **Interactions**: Vanilla JavaScript with Intersection Observer for scroll logic.
- **Icons**: Lucide for ecosystem-wide continuity.
